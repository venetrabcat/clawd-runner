# CLAWD RUN — бесконечный раннер

## О проекте

Бесконечный раннер на canvas: пиксельный маскот CLAWD бежит сам, дорога
не кончается, препятствия несутся навстречу. Игрок только прыгает и
пригибается. Скорость всё время растёт; врезался — забег закончился,
restart запускает новый забег без перезагрузки страницы.

## Референс

Механика отталкивается от Chrome Dino Game (компонент
`components/neterror/resources/dino_game`): геймплей-контур изучен —
автобег, прыжок с переменной высотой, пригибание, спавн препятствий
в зависимости от скорости, AABB-коллизия с отступом, счёт за дистанцию,
лучший результат, рестарт без перезагрузки. Код и графика не копируются —
реализация и пиксель-арт собственные.

## Принятые решения

- **Маскот** — CLAWD (пиксельный кролик Claude Code) из
  `~/Downloads/clawd.svg` (17×11, цвета #CD7B5A и #1A1A1A). Спрайт описывается
  пиксельной картой в JS и рисуется на canvas; кадры бега и позу пригибания
  авторим сами.
- **Управление** — маскот бежит сам; игрок прыгает (короткий и высокий
  прыжок) и пригибается. Клавиатура + тач.
- **Столкновение** — врезался: забег закончился; restart без перезагрузки.
- **Азарт** — лучший результат рядом со счётом, хранится в localStorage,
  перебить хочется.
- **Скорость** — растёт со временем и дистанцией: выше темп, плотнее
  препятствия.

## Структура файлов (единственно допустимая)

```
index.html
styles.css
script.js
CLAUDE.md
```

Других файлов не добавляем: без ассетов, картинок, конфигов, шрифтов.

## Строгие правила

- Только `index.html`, `styles.css` и JavaScript в одной папке, рядом.
- Без npm, сборщиков, фреймворков и бэкенда: открыл `index.html` в браузере —
  всё работает (`file://`).
- Без внешних шрифтов, CDN и сетевых запросов (никакого fetch, внешних URL).
- Один namespace `window.CLAWD`; весь JS в одном `script.js`, классический
  скрипт с `defer`.
- Без inline-стилей и inline-скриптов — всё в `styles.css` и `script.js`.
  Динамическое canvas-рисование и `transform` из animation loop — это
  необходимо для анимации и не считается inline-стилем.
- Строки интерфейса — на английском; пояснения и подписи — на русском.
- Пиксель-арт CLAWD и все анимации — собственные, по мотивам `clawd.svg`,
  без копирования чужих спрайтов и кода.

## Порядок работы

1. Сначала согласуем рамки и план.
2. Работаем по этапам MVP; после каждого шага проверяем видимый результат
   в браузере.
3. Открываем проект как `index.html` через `file://` — без сервера.
